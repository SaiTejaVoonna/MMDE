# MMDE — Roadmap

## Phase 1 — Foundation

- [ ] Define canonical media model
- [ ] Define normalized music/track model
- [ ] Define provider interfaces
- [ ] Create project structure
- [ ] Add basic media search

## Phase 2 — Anime MVP

- [ ] Resolve anime titles
- [ ] Discover opening themes
- [ ] Discover ending themes
- [ ] Discover insert songs
- [ ] Discover character songs where available
- [ ] Discover OST / original score releases
- [ ] Organize by season / movie / special
- [ ] Normalize duplicate records

## Phase 3 — Music identity

- [ ] Add music identity resolution
- [ ] Prefer ISRC and stable identifiers
- [ ] Add release / album relationships
- [ ] Add confidence handling
- [ ] Add false-match protection

## Phase 4 — Platform links

- [ ] Spotify
- [ ] Apple Music
- [ ] YouTube / YouTube Music
- [ ] Deezer
- [ ] Additional platforms

## Phase 5 — Broader media

- [ ] Movies
- [ ] TV shows
- [ ] Indian / Telugu cinema
- [ ] Western media
- [ ] Games
- [ ] Specials and other media formats

## Phase 6 — UX and performance

- [ ] Fast title search
- [ ] Add-to-discovery workflow
- [ ] Discovery progress states
- [ ] Caching
- [ ] Duplicate handling
- [ ] Source attribution
- [ ] Confidence indicators

## Guiding rule

Do not add integrations just for the sake of adding integrations. Build the core media-to-music graph and matching logic first.
